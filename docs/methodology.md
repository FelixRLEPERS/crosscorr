# Методология

1. **Унификация** — приведение всех данных к формату `timestamp_utc, detector_id, detector_type, residual`.
2. **Базовая модель** — `v0 ~ T_заряда + масса + (1|полигон)` (statsmodels MixedLM).
3. **Пространственная модель** — PyMC с экспоненциальным ядром ковариации.
4. **Кросс-корреляция** — матрица корреляций между детекторами.
5. **MFDFA** — мультифрактальный анализ.
6. **Surrogate-тесты** — 1000+ фазовых суррогатов.
7. **FDR-коррекция** — контроль ложных обнаружений.
