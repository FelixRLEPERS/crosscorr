# Методология

## 1. Унификация данных
Все данные приводятся к формату: `timestamp_utc, detector_id, detector_type, residual`.

## 2. Базовая модель
`v0 ~ T_заряда + масса + (1|полигон)` через statsmodels MixedLM.

## 3. Пространственная модель
PyMC с экспоненциальным ядром ковариации по расстоянию.

## 4. Кросс-корреляция
Матрица корреляций между всеми детекторами.

## 5. MFDFA
Мультифрактальный анализ временных рядов.

## 6. Surrogate-тесты
1000+ фазовых суррогатов для проверки значимости.

## 7. FDR-коррекция
Контроль ложных обнаружений.
