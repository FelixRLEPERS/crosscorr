# 2026-09-23 · Сравнение наивного p-value и ESS

## Что сделано
- Реализована ESS-коррекция (P1-2)
- Реализован block bootstrap (P1-3)
- Реализован модуль confounders (P1-6)
- Интегрированы флаги --use-ess и --remove-confounders
- Спринты 1-3 (гигиена, архитектура, интеграция)

## Научный результат
На синтетике (10 детекторов, 720 часов, AR(1) φ=0.7):

| Режим | Значимых пар |
|---|---|
| Наивный p-value | 45 / 45 |
| ESS-коррекция | 2 / 45 |

**Вывод:** наивный p-value даёт ложные открытия в 20 раз чаще.
ESS обязателен для геофизических данных с автокорреляцией.
