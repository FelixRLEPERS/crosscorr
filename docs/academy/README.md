# CrossCorr Academy — учебный слой

Этот раздел — для Макара (13) и Егора (11). Здесь только задачи, которые
реально можно сделать в нашем коде и проверить командой.

Общий принцип: **одна задача = одна ветка `feature/...` = один PR**.
CI должен быть зелёным до merge. Ревью: Макар делает — Егор проверяет
и запускает — Алексей ревьюит код.

Как проверять себя:
```
python -m pytest tests/ -m "not slow" -q
python -m ruff check crosscorr_lib/ tests/ scripts/ data/
```

## Правила для обоих

1. Ветку называем по задаче: `feature/egor-wspr-rows`.
2. Не трогаем `crosscorr_lib/analysis/surrogate.py`, `mantel.py`,
   `pairs.py` без папы — там сложная статистика.
3. Если что-то непонятно — это нормально. Спросить лучше, чем гадать.
4. После merge — запись в `docs/journal/` (что сделал, чему научился).
