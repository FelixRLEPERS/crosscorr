## 📄 PAPER I — ЧТО ОПУБЛИКОВАНО

**Название:** "Scale-dependent WSPR response to geomagnetic storms: frequency dependence and baseline-invariant absolute loss"

**Публикация:** Zenodo, 2026-10-10
- **Concept DOI:** `10.5281/zenodo.23283375`
- **Version DOI (v1.0.1):** `10.5281/zenodo.23285981`
- **GitHub:** https://github.com/FelixRLEPERS/crosscorr
- **Лицензия:** MIT (код), CC BY 4.0 (препринт)
- **Объём:** 20 страниц, 5 рисунков, 9 таблиц, 24 references
- **Локальный PDF:** `G:\crosscorr\paper\main.pdf` (834 KB)

**Данные:**
- WSPR hourly aggregates (20 м, 40 м, 15 м) из wspr.live
- Training: апрель 2024 – сентябрь 2025 (18 мес)
- Held-out: январь – март 2026 (3 мес)
- 39 456 WSPR hours, 198 storm hours (Kp ≥ 5)
- Kp (GFZ Potsdam), Dst (WDC Kyoto), F10.7 monthly (NOAA SWPC)

**Основные результаты:**
1. Spot density drops 27–39% during Kp ≥ 5 storms on all three bands (block permutation p < 0.0001, 10 000 iterations, block = 24 h).
2. Scale-dependence: −18% at Kp 5–6, −42.8% at Kp ≥ 6, −53% at Kp ≥ 7.
3. Independent replication on held-out period (all p ≤ 0.014).
4. Baseline-invariant absolute spot loss на 40 м: −18 300 spots/h в training и held-out, несмотря на +38% network growth.
5. Day/night asymmetry: 40 м провал сильнее ночью в 9/10 месяцев.

**Методы:**
- Diurnal-seasonal residual baseline (month, hour_of_day, day_of_week).
- Binned analysis по Kp-бинам.
- Block permutation test (24 h blocks, 10 000 iterations).
- Effective sample size: ESS = N·(1−ρ₁)/(1+ρ₁), ESS ≈ 82.
- Benjamini-Hochberg FDR на 6 тестов (p_FDR = 0.0).
- 6 robustness checks.

**Известные ограничения (в paper §5.5):**
- 18 месяцев ≠ климатология.
- Held-out только N = 23 storm hours.
- Spatial resolution: глобальный агрегат маскирует региональные эффекты.
- F10.7 только monthly, не включён в модель.
- Dst provisional.
- Block permutation предполагает within-block stationarity.
- Summer 15 м может быть частично contaminated sporadic-E.

## 🧮 PAPER II — ФИЗИЧЕСКАЯ МОДЕЛЬ τ(d, f)

### Зачем это здесь
Пилот Paper II провалился не потому, что метод был плох, а потому что мы искали **направление LSTID** без явной формулы, которую проверяем. Три вывода из пилота — это симптомы отсутствия модели. Ниже — модель, которая превращает Paper II из «heatmap-угадайки» в **регрессию двух физических параметров**.

### Формула
В ионосфере нет единой скорости волны. Есть **два аддитивных механизма**:

$$ \tau(d, f) = \tau_0(f) + \frac{d}{V_{\text{TID}}(f)} $$

где:

$$ \tau_0(f) \approx \tau_{\text{mag}} + \frac{A}{f^2} $$

- **$V_{\text{TID}}$** — скорость крупномасштабных перемещающихся ионосферных возмущений (LSTID). Литература: **300–400 м/с** для экваториального распространения от авроральной зоны; **~100 м/с** для медленной отрицательной фазы.
- **$\tau_{\text{mag}}$** — магнитосферно-ионосферный перенос, ~20 мин.
- **$A/f^2$** — частотно-зависимый отклик D-слоя (абсорбция ∝ 1/f²).

### Два режима — два теста

| Режим | Доминирует | Ожидаемая зависимость |
|---|---|---|
| **Волновой** (LSTID) | Авроральный источник, бежит к экватору | $\tau$ **растёт линейно с $d$**, слабо зависит от $f$ |
| **Химический** (O/N₂) | Изменение состава термосферы на месте | $\tau$ **не зависит от $d$**, сильно зависит от $f$ |

**Пилот May 2024 дал «VERTICAL / INCONCLUSIVE»** — это ровно тот случай, когда $b(f) \approx 0$, то есть химический режим. Но пилот не мог этого показать, потому что не строил регрессию $\tau(d)$. Теперь может.

### Протокол проверки (Paper II redesign)
1. **Построить куб $C(\tau, d, f)$**: Для каждой пары TX–RX вычислить $d$ по большому кругу. Сгруппировать по частотным бэндам WSPR. Для каждого бина $(d, f)$ — кросс-корреляция между `residual` и Kp/Dst со сдвигом $\tau$. Максимум по $\tau$ → $\hat{\tau}(d, f)$.
2. **Регрессия $\hat{\tau}(d) = a(f) + b(f) \cdot d$ для каждого $f$**: 
   - $b(f) > 0$ значимо → волновой механизм.
   - $b(f) \approx 0$ → химический механизм.
   - $1/b(f) \approx V_{\text{TID}}$ — **прямое измерение скорости**.
3. **Частотная зависимость $\hat{\tau}_0(f)$**: Проверить $\hat{\tau}_0(f) \sim A/f^2$ → свидетельство D-слоя.
4. **Статистическая защита**: Block permutation, Max-statistic по $\tau$, FDR Benjamini-Yekutieli, Bootstrap по спотам → CI для $b(f)$ и $\hat{\tau}_0(f)$, Байесовский анализ (постериор $V_{\text{TID}}$).
5. **Локальное время**: Разделить на окна 06–10 LT и 11–14 LT («запрещённый интервал»). Сравнить параметры между окнами.

### Скелет `scripts/tau_regression.py` (Задача 9)
```python
"""
tau_regression.py — Skeleton for Paper II LSTID velocity regression.
Protocol: τ(d, f) = τ_0(f) + d / V_TID(f)
Input: storm_day_agg.parquet, quiet_all_agg.parquet
Output: b(f) [slope], a(f) [intercept], V_TID(f) with bootstrap CI.
"""
import pandas as pd
import numpy as np
from scipy import stats
import warnings

def bootstrap_regression(d, tau, n_bootstraps=1000, ci=0.95):
    """Performs linear regression with bootstrap confidence intervals."""
    slopes, intercepts = [], []
    n_samples = len(d)
    
    for _ in range(n_bootstraps):
        # Resample with replacement
        indices = np.random.choice(n_samples, n_samples, replace=True)
        d_boot, tau_boot = d[indices], tau[indices]
        
        # Linear fit
        slope, intercept, r_value, p_value, std_err = stats.linregress(d_boot, tau_boot)
        slopes.append(slope)
        intercepts.append(intercept)
        
    # Calculate confidence intervals
    alpha = 1 - ci
    lower_slope, upper_slope = np.percentile(slopes, [alpha/2 * 100, (1 - alpha/2) * 100])
    lower_int, upper_int = np.percentile(intercepts, [alpha/2 * 100, (1 - alpha/2) * 100])
    
    # Final fit on full data
    final_slope, final_intercept, _, _, _ = stats.linregress(d, tau)
    
    return {
        "slope": final_slope,
        "slope_ci": (lower_slope, upper_slope),
        "intercept": final_intercept,
        "intercept_ci": (lower_int, upper_int),
        "v_tid": 1.0 / final_slope if final_slope > 0 else np.nan,
        "v_tid_ci": (1.0/upper_slope if upper_slope>0 else np.nan, 
                     1.0/lower_slope if lower_slope>0 else np.nan)
    }

def main():
    print("Loading data...")
```
