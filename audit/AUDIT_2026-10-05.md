#### P0-1. NaN в данных обращается в максимальную значимость (pairs.py)

- Severity: P0

#### P1-5. Диапазон сдвигов в `_time_shift` смещает нулевую модель

- Severity: P1

## 3. Статистическая валидность

### 3.1 BH / BY

- H0: p-value каждого теста соответствует нулевой гипотезе; контроль FDR на уровне alpha.
- T: ступенчатая процедура (step-up).
- P: `p_sorted <= alpha * k / n` (BH) или `<= alpha * k / (n * c(m))` (BY), `c(m) = sum(1/k, k=1..n)`.
- M: BH или BY по `m_finite` тестам.

Оценка: реализация **корректна**. Проверено по `surrogate.py:164` (гармоническая сумма), `:173` (порог BY), `:181-183` (q-value с монотонизацией через `np.minimum.accumulate[::-1]` и клипом), `:232-245` (BH). NaN исключаются через `finite_mask` и заменяются на `NaN` в q (`:187, 249`) — это правильное поведение. При `m = 0` возвращаются пустые массивы (`:154`). Монотонность обеспечена в обеих ветках.

Замечания:
- Знаменатель берётся по `n_finite`, а не по общему `m`. Это защитный выбор, задокументирован в коде, но формально отличается от классической формулировки BY, где `c(m)` считается по всем тестам. Следует явно указать это в `docs/methodology.md`. Severity: P3.
- Проверки на «все p равны» и «только одна пара» в коде отсутствуют, но обе корректно обрабатываются общей формулой (`n_finite = 1` → порог `alpha / c(1) = alpha`). Severity: Info.

### 3.2 Max-statistic null

- H0: между x и y нет связи ни на одном из `2*max_lag+1` лагов.
- T: `max_tau |z(rho_tau)| * sqrt(n_tau - 3)` — Fisher-weighted (`surrogate.py:437-483`).
- P: `(n_extreme + 1) / (n_surrogates + 1)` (`surrogate.py:384`) — правило Davison-Hinkley.
- M: max-statistic поглощает поиск по лагам; поверх применяется BY по парам (`cross_correlation.py:261-263`).

Оценка: **методологически корректен**. Наблюдаемая и нулевая статистики вычисляются одной функцией `fisher_weighted_max_stat` (строки 345 и 375) по одному и тому же вектору `n_lags`. Bonferroni поверх max-stat не применяется — это подтверждено отсутствием деления на число лагов. Правило `+1` соблюдено.

Замечания:
- **P1**: знаменатель p-value не учитывает пропущенные суррогаты (P1-2).
- **P1**: `n_lags` для суррогатов берётся из реальных данных (строка 375), а не пересчитывается. Это внутренне непротиворечиво (одинаковая статистика на наблюдении и нуле), но суррогаты строятся с интерполяцией NaN (`_phase_surrogate_keep_length:422`) и потому имеют больше валидных точек, чем реальные данные. Следует зафиксировать это решение в методологии. Severity: Info.
- **P1**: Fisher-вес `sqrt(n-3)` (строка 477) корректен, но при `n <= 3` лаг отбрасывается через `finite` (`:468`) без попадания в p-value. Это консервативно и корректно.
- **P0**: max-statistic используется только в недефолтном пути (P0-3), а ESS-перезапись его результата делает комбинацию бессмысленной (P0-4).
