### V2-02. Фикс P2-6 применён только к `effective_sample.py`

- class: BUG | severity: P0 | было_в_аудите_v1: partial

Фикс P2-6 (сохранение длины ряда при NaN) применён в `effective_sample.py:54` (`np.interp`). Но `surrogate.py` содержит три функции с тем же дефектом компактирования:

`crosscorr_lib/analysis/surrogate.py:29` — `phase_surrogate`:
```python
x = x[~np.isnan(x)]
if x.size < 4:
    return np.full_like(x, np.nan, dtype=float)
```
NaN выбрасываются **до** проверки длины, поэтому при n≥4 с NaN функция возвращает суррогат **укороченной длины**. Длина суррогата ≠ длина наблюдения.

`crosscorr_lib/analysis/surrogate.py:437-444` — `_phase_surrogate_keep_length` (используется дефолтным max-stat путем, строка 381):
```python
if mask.sum() < 4:
    return x          # <- возвращает исходный ряд, НЕ суррогат
...
if n < 4:
    return x          # <- то же
```
Возврат исходного ряда в нулевом распределении — ровно тот дефект, который P1-3 закрыл в `phase_surrogate:33`.

`crosscorr_lib/analysis/surrogate.py:538-546` — `iaaft_surrogate`:
```python
if n < 4:
    return x.copy()
...
if good.sum() < 4:
    return x.copy()
```
Тот же нефиксенный дефект P1-3.

Severity P0 по трём причинам: (а) `phase_surrogate` и `surrogate_test` экспортированы в публичном API (`crosscorr_lib/__init__.py:42,43,61,62`); (б) `surrogate.py:271 main()` — живой CLI-путь; (в) наблюдение и нуль считаются на разной длине, что нарушает базовое требование к суррогатному тесту.

Severity P1, если ограничить `_phase_surrogate_keep_length:437-444` и `iaaft_surrogate:538-546` (защита `mask.sum() < 4` недостижима на практике, т.к. вызывающая сторона уже отфильтровала короткие ряды).

### 4.1 FDR (3.1)

**BH (`surrogate.py:228-267`) — проверено численно, корректно:**

- `thresholds = alpha * np.arange(1, n_finite+1) / n_finite` (строка 248) — правило BH;

- `q_local = p_sorted * n_finite / np.arange(1, n_finite+1)` (строка 256) — правильно;
- монотонность через `np.minimum.accumulate(q_local[::-1])[::-1]` (строка 257) — **реализовано верно**;
- `np.clip(q_local, 0, 1)` (строка 258);
- `m == 0` → пустые массивы (строки 231-232);
- `n_finite == 0` → `zeros(m, bool)` + `full(m, nan)` (строки 238-239) — корректно;

**BY (`surrogate.py:141-205`) — проверено численно, корректно:**
